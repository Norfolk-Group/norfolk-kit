Motion catalog — the vocabulary, not a gallery

Every animation in src/components/animations, grouped by family, with its real timings. Reach for one of these before inventing new motion. The controls retime every specimen at once, so you can judge speed against the whole set rather than one card in isolation.

Lascaux — self-drawing marks

4 components

Cave-painting-derived glyphs that draw themselves stroke by stroke, flicker as if firelit, and are periodically re-traced by a bright white "hand" before dissolving into the next figure. The warm counterweight to the geometric families. Path data is the original hand-drawn mark data, unmodified.

Cube — Swiss geometry

3 components

A 3×3×3 cluster of 27 cubies. The whole cube turns slowly while individual cubies tumble and breathe outward on their own clock, so the form reads as continuously disassembling and reassembling. Precise, technical, monochrome.

Solver — visible working

4 components

Motion that shows effort: expansion, convergence, rebalancing. Use these where a wait has substance behind it and the user benefits from seeing that something is being worked through rather than merely awaited.

Orb — presence indicators

5 components

Small, persistent, one per persona. Every orb is phase-driven — the same geometry speeds up and brightens from idle through synthesizing. Change the phase control above to see the full range; it is the same knob the application drives. Note these are five distinct geometries, not one component recoloured.

Orbit — for longer waits

2 components

Three tilted rings of beads around a beating core. Beads randomly "spark" inward, trailing light. Swiss is the calm monochrome original; Advanced shares its geometry exactly and layers on nine distinct spark behaviours, an accent palette, and a core that gets nudged when a bead fires.

How faithful is this page?

These are vanilla SVG/CSS recreations, rebuilt from the source components' literal timings, easings, colours and path data. They are not the React originals — a self-contained page cannot load framer-motion.

Close on the Lascaux family (exact path data, same draw/flicker/trace choreography) and the orbs and cube grids. Deliberately simplified where the original is driven by random state machines: AnalystThinkingCube's nine poses, BarChartPulse's scene shuffle, and the orbits' spark selection all run here on a fixed cycle rather than the original's randomness. Treat this as the motion vocabulary reference, not a pixel-diff target.

Not shown

  • AgentThinkingState and AgentWaitingOverlay — composed wrappers that select a family and own the full waiting UX. They carry the H-Analytics agent taxonomy and need adapting per project, so they are not primitives.
  • AnalystCubeR3F — a WebGL variant, deliberately excluded from the kit.
  • RebeccaAliveGeometry renders 12 independent glyph fragments; shown here reduced for legibility at card scale.

Using these

Import from src/components/animations; resolve by key through animation-registry.ts rather than hardcoding a component, so the choice stays data.

Always honour useReducedMotion.ts — this page does too; switch your OS to reduced motion and every specimen freezes to a drawn resting state. That is an accessibility requirement in the design system, not a nicety.

New motion should reuse an easing curve already on this page. The recurring one is cubic-bezier(.23,1,.32,1).
