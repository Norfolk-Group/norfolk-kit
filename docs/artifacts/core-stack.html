02The two verbs

Spoken in plain English to Claude Code, in any repo, any environment. Deliberately separate: one only adds, the other moves — so equipping mid-project can never trigger a reorganization you didn't ask for.

"equip this repo" — additive · run ~once per repo

Works on brand-new and ten-year-old repos alike.

YouSay the verb
Claude CodeReads the kit from GitHub + what this repo already has
Claude CodeAdds what's missing; flags conflicts, never overwrites
YouRead plain-English PR summary → approve

Yesterday's baseline: this took an hour of terminal pain (chmod, auth, stash, GPG). Target: minutes of your attention.

"tidy this repo" — reorganizing · run periodically

Audits any repo against the canonical layout — equipped or not.

YouSay the verb
Claude CodeAudits vs canonical layout: misplaced files, stale artifacts, junk at root
Claude CodeProposes moves; questionable items → archive/, dated
YouReview → approve

Never silently deletes. True deletions are listed for explicit approval in the PR description.

03The settled stack — one answer per category

Deep-researched 2026-07-31 by four parallel agents against official July-2026 pricing and docs. Risks stated, not hidden. These become kit decision records — nobody re-opens them casually.

Hosting
Railway KEEP
The only option that runs the real stack — long-lived Express servers, cron, workers, WebSockets — with zero rewrite. ~$5–15/mo per app. Vercel's functions cap at ~13 min and would force re-architecting every app.
8-hr outage May 2026 (GCP suspension). Mitigated: data (Neon) and files (R2) live off Railway — an outage degrades, never destroys. Add a status monitor.
Database
Neon KEEP
Instant, near-free database branches for safe testing — the reference standard. 80% storage price cut post-acquisition. Migrated this week, working.
Auth
WorkOS KEEP
Built for invite-only portals; enterprise SSO ready when investors demand it; 1M users free; an admin screen a non-programmer can run.
File storage
Cloudflare R2 KEEP
$0 downloads, forever — structurally decisive for a document-download portal. 252 files migrated yesterday, in production.
Embeddings / AI search
Voyage AI STANDARD
Cheapest frontier option ($0.06/M vs $0.12–0.15 rivals); the only vendor Anthropic names; new models still shipping post-MongoDB acquisition. Undo-cost if ever needed: ~$3.
MongoDB could steer it toward their own bundle someday — the $3 escape hatch covers it.
Secrets · Email · Errors
Doppler · Resend · Sentry KEEP
In production, working, not re-opened.
All-in-one platform
Supabase NOT ADOPTED
Would downgrade two pillars (weaker branching than Neon, consumer-grade auth vs WorkOS) to gain one dashboard — and its client-direct security model fights the tRPC architecture. Would burn this week's completed migrations.
realtime collaboration (live presence/cursors) becomes a hard requirement — and even then, try a standalone realtime service first.
Hosting alternative
Vercel (as host) QUESTION CLOSED
Doesn't run servers — runs short-lived functions. The Vercel AI SDK (a code library) stays in the stack; Vercel the host is out. The frontend+backend split adds two dashboards and CORS plumbing for CDN benefits the apps don't need.
Containers
Docker INVISIBLE BY DESIGN
Already working for you unseen: every Codespace is a container; Railway auto-packages every deploy (Railpack). Standard containers = insurance — moving hosts is days, not months. The kit never requires hand-written Dockerfiles; exceptions (self-hosted Docker-only tools, PDF renderers) need a decision record.
